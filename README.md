# Description
This is a simple application that allows you to search for users by name and country, filter by country, and sort by created date.

# Tech Stacks
- [Expo](https://expo.dev/) - A framework and platform for universal React applications
- [TypeScript](https://www.typescriptlang.org/) - A typed superset of JavaScript
- [Day.js](https://day.js.org/) - Fast 2kB alternative to Moment.js with the same modern API
- [React Native Country Flag](https://www.npmjs.com/package/react-native-country-flag) - A React Native library for displaying country flags
- [Country List](https://www.npmjs.com/package/country-list) - A library providing comprehensive country data including:
  - Country names
  - ISO codes

# How to run
1. Clone this repository
2. Create an .env file
3. Copy the contents of .env.example file and paste it into the .env file
4. Open the terminal window and run the following commands:

```bash
pnpm install
pnpm ios or pnpm android
